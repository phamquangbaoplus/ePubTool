ePubTool — Installation
======================
Requires Apple Silicon and macOS 27 or later.

1. INSTALL
Drag ePubTool.app onto the Applications shortcut in this window.
Wait for the copy to finish. Do not run the app from this disk image.

2. FIRST LAUNCH
Open Terminal, paste this single line, and press Return:

xattr -dr com.apple.quarantine "/Applications/ePubTool.app" && open "/Applications/ePubTool.app"

Use this only for a release from the ePubTool GitHub repository that you
trust. It removes download quarantine from this app only. The app is
ad-hoc signed, not notarized by Apple. It does not disable Gatekeeper
system-wide. Repeat after an update if needed.

3. REQUIRED: FULL DISK ACCESS
To read your Apple Books library:
- Open System Settings > Privacy & Security > Full Disk Access.
- Click + and select /Applications/ePubTool.app. Authenticate if asked.
- Turn on the switch for ePubTool.
- Quit ePubTool completely (Command-Q), then reopen it from Applications.
- Select Manage Apple Books and click Refresh.

The Terminal command does not grant Full Disk Access. You must enable
this permission yourself in System Settings. After an update, if access
stops working, remove the old entry and add the installed app again.

4. FINISH
Eject this disk image. Open ePubTool from Applications in future.

TROUBLESHOOTING
- "No such file": confirm the app is at /Applications/ePubTool.app.
- If opening is still blocked, try opening the installed app once, then
  use System Settings > Privacy & Security > Open Anyway, if available.
- This command cannot fix damaged downloads, incompatible macOS versions,
  or restrictions applied by your organization's administrator.
